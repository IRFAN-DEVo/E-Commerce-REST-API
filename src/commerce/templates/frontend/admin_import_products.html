File Requirements

  • Products file max: 50 MB
  • ZIP file max: 500 MB
  • Formats: CSV, XLSX
  • Required columns: Name, Price
  • Optional: Category, Brand, Stock, Description
  • Image columns: Main Image, Gallery Images
  • ZIP images max per file: 10 MB
  • Allowed image types: JPG, PNG, WebP

ZIP Structure

Place all images at the root of the ZIP (no sub-folders):

images.zip
 ├─ iphone.jpg
 ├─ iphone1.jpg
 ├─ iphone2.jpg
 └─ galaxy.jpg

Reference them in the Main Image and Gallery Images columns by filename.

Tips

  • Download the template to see the correct format
  • Gallery images are comma-separated
  • Leave Gallery Images blank for products with no gallery
  • Use Skip for safe first-time imports
  • Use Replace to fully refresh product images
  • Missing images in the ZIP are logged as warnings, not errors
